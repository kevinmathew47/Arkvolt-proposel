ARKVOLT Proposals - staff laptop setup
=====================================

1. Copy the ZIP to the laptop (USB / Google Drive / WhatsApp) and UNZIP it:
   right-click the ZIP -> Extract All -> Extract.
2. Open the extracted folder and double-click  Setup
   - The ARKVOLT setup window opens. Click Install.
   - It checks the laptop (Windows, disk space, internet, Microsoft Edge, Python)
     and downloads anything that is missing. No administrator password is needed.
   - First time: about 5 minutes. Each step gets a green tick.
   - If Windows shows "Windows protected your PC", click "More info" -> "Run anyway".
3. Click "Open ARKVOLT Proposals". The browser shows "Set up this laptop" -
   the owner/manager fills it in once: staff name, username and password, the admin
   password, and the device key from the online dashboard
   (https://arkvolt-proposel.vercel.app -> Staff & devices -> + Add a staff laptop).
   The key can also be left blank and entered later on the Account page.
   Lost key? On the dashboard click "New key" on that laptop's row and paste it
   in the app: Account -> Online dashboard -> Save & test connection.
4. Done. From then on: double-click "ARKVOLT Proposals" on the desktop.
   (No black window - a small ARKVOLT screen appears, then the browser opens.)

To update the app later (new prices, new version): unzip the new folder and run Setup again.
Proposals already made on the laptop are kept.

If something goes wrong, the setup window says what, and "Show details" has the full log.
